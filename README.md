# 💰 Smart Expense Tracker

A simple Java-based application for managing income and expenses.

## 📌 Features

* Add income
* Add expenses
* Categorize expenses
* View all expenses
* Calculate total expenses
* Check available balance

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

## 💡 How It Works

The user can add income and record expenses by entering the category and amount. The application stores the expenses and calculates the total expense and remaining balance.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `SmartExpense.java` in a Java IDE.
3. Compile and run the program.
4. Select options from the menu.
